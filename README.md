## Selected research

- **[MapScout](https://www.amazon.science/publications/mapscout-an-agentic-harness-for-map-editing-and-geospatial-data-labeling)** · ACM SIGSPATIAL 2026 demo. Agents use imagery, map data, and GPS traces to propose edits. Tools check the geometry and connectivity; people make the final call.
- **[Transferring the long tail](https://www.amazon.science/publications/transferring-the-long-tail-composing-geometric-and-llm-based-stitching-for-cross-provider-map-migration)** · IEEE Big Data 2026. Use geometric rules first, then a multimodal agent to select candidate connections in harder cases.
- **[Scalable conflation](https://www.amazon.science/publications/scalable-conflation-for-maps-data-replay-between-heterogeneous-geospatial-data-sources)** · ACM SIGSPATIAL 2026. Transfer attributes and turn restrictions across map providers at scale.
